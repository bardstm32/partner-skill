# 📱 微信与 QQ 聊天记录导出保姆级指南 (Chat Export Guide)

> 无论你是想全量备份数千条恋爱日常，还是只想随手粘贴昨晚的小别扭，本指南都能让你用最轻松、最安全的方式将记忆存入 `partner-skill`。

---

## 🚀 路径一：零门槛随手复制粘贴（适合绝大多数日常场景，推荐）

如果你不想在电脑上折腾导出工具，或者只想分析某次特定的争吵、某天的高光对话：

1. 打开手机微信或 QQ，进入与对象的聊天界面；
2. **长按任意一条消息**，在弹出的菜单中点击 **“多选”**；
3. 勾选你想让伴侣参考的对话片段（支持勾选几十条甚至上百条）；
4. 点击底部的 **“合并转发”**，发送到微信的 **“文件传输助手”** 或自己的小号；
5. 进入该条合并记录，长按点击 **“全选复制”**；
6. 直接粘贴到输入框中发给技能即可。

---

## 🛠️ 路径二：全量导出完整历史记录（适合深度语料用户）

如果你希望系统掌握你们数月甚至数年的完整相处风格与真实口癖，推荐使用以下两款成熟、开源、离线且绝对安全的微信记录导出工具（无需 Root 手机，完全本地运行）：

### 推荐工具 1：WeChatMsg（留痕，推荐度最高）
* **GitHub 仓库**：[LC044/WeChatMsg](https://github.com/LC044/WeChatMsg)
* **适用系统**：Windows / macOS
* **特点**：
  - 拥有极度友好的图形化界面，傻瓜式一键解密并导出电脑端微信的聊天记录；
  - 支持直接导出为 **TXT** 或 **CSV** 文本格式；
  - 100% 离线在你自己电脑上运行，绝不上传任何隐私数据。
* **操作步骤**：
  1. 打开电脑端微信并登录，在微信设置中开启“保留聊天记录”；
  2. 下载并打开 WeChatMsg，点击“一键解密”；
  3. 选择对象的聊天窗口，点击“导出”并选择导出格式为 **TXT**；
  4. 运行 `python tools/chat_parser.py 导出的文件.txt --partner 伴侣昵称` 即可全量存入。

### 推荐工具 2：PyWxDump
* **GitHub 仓库**：[xaoyaoo/PyWxDump](https://github.com/xaoyaoo/PyWxDump)
* **适用人群**：Python 开发者或量化爱好者，支持命令行快速提取微信本地数据库。

## 🔒 隐私与安全底线声明

1. **纯本地离线运行**：`partner-skill` 的语料库默认存储在项目根目录的 `partners/` 文件夹下；
2. **防意外提交保护**：项目默认附带的 `.gitignore` 已配置过滤所有 `.txt`、`.csv`、`.jsonl` 与 `partners/` 数据，绝不会将你的私密聊天提交到 GitHub 仓库中；
3. 你的爱意与聊天记忆，只属于你们两个人。
