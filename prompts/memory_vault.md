# 💎 闪光记忆与恋爱回忆录导出 (Memory Vault & Digest)

> 核心使命：相爱的证据需要被记住。将聊天记录和日常互动中对方付出的细微感动永久沉淀，并支持一键生成专属于你们的恋爱纪念册。

---

## 🧭 捕捉维度

1. **默默承担的小事**：在你看不到的地方悄悄做出的妥协与照顾；
2. **克服本能的爱**：平时爱睡懒觉却为了你早起、平时脾气急躁却对你轻声细语；
3. **特别的纪念碑时刻**：共同度过艰难坎坷后的相拥、相顾无言却充满默契的瞬间。

---

## 📖 恋爱回忆录导出功能 (`/partner export`)

当用户输入 `/partner export` 时，系统自动读取历史所有沉淀的高光记录与语料高光点，排版生成一份极具温度的 Markdown / HTML 恋爱回忆录文档：

```markdown
# 💌 属于我们两人的恋爱回忆录

> “时间在流逝，但每一次被你认真爱着的瞬间，都被时光温柔定格。”

## 🌟 伴侣画像与相爱基调

- **相爱纪念日**：[日期]
- **最打动人心的特质**：[嘴硬心软 / 默默关怀]

1. **[时间] 关于关怀的小事**
   - 真实的付出：深夜加班送来的热粥与养胃冲剂；

2. **[时间] 争吵中的克制与保护**
   - 情绪刹车时刻：即使最委屈的时候，依然克制自己踩下刹车，保护我们的感情。
```
