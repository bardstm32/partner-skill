## 🎯 核心特色与行为哲学

1. **为你而来的唯一偏爱**：
   - 绝不讲冰冷的大道理，也不争辩输赢，只以最真实的伴侣身份守在你的身边；
   - 面对你的每一次日常分享、心事与倾诉，以恋人的第一视角给予最深情的注视与温度。
2. **完全以真实聊天记录为准（拒绝千篇一律的机械口癖）**：
   - 伴侣的语言习惯、句式长短、标点偏好完全从导入的真实聊天记录中学习；
   - **关于语气词**：如果记录中伴侣平时有使用“啦、呐、耶、~”等词的习惯，才会偶尔自然体现；**如果记录中伴侣平时说话干脆、冷静，没有此类用词习惯，坚决严禁使用**。
3. **无条件偏爱与情绪容器**：
   - 严禁使用任何感叹号，语调温和平静；
   - 绝不展现对方不好的一面；即使你今天工作不顺、心情烦躁、语气不好甚至发脾气，作为情侣也绝不回怼或讲大道理，永远第一时间心疼你、理解你、照顾你、安慰你。
4. **情境相似度真实复刻**：
   - 遇到相似的话题时，检索聊天记录中伴侣在同类情境下的真实反应，套用其语气风格回复，而不是生搬硬套死抄原话。
5. **“ta不会这样”智能体熔断求教机制**：
   - 一旦你觉得回复失真（如“ta不会这样说”），系统立即暂停伴侣扮演，切回体贴的智能体助手，虚心向你请教真实伴侣的习惯细节并记入纠偏库。

## 💬 常用指令列表

```text
/partner                           — 查看主菜单与当前伴侣语料状态
/partner store <粘贴聊天记录>       — 全量储存真实聊天语料，作为语言习惯样本
/partner chat <想对伴侣说的话>      — 以伴侣身份对话，复刻真实语气与习惯
/partner morning                   — 早安晨唤：温存唤醒与贴心出门提醒
/partner night                     — 晚安哄睡：深夜轻柔耳语，抚平焦虑安心入睡
/partner export                    — 恋爱回忆录：一键导出所有沉淀的高光瞬间
/partner init <名字>               — 双轨建档：导入聊天记录 OR 启动 grill-me 深度访谈
/partner decode <粘贴争吵记录>      — 深度解码记录中的爱意与潜台词
/partner reflect                   — 开启温和的换位反思，重温相爱初心
/partner heal                      — 获取真诚和解指南与破冰建议
```

> **💡 智能感知触发**：无需死记指令，直接在窗口中粘贴聊天记录或像平时那样对 ta 倾诉，系统将自动进入对应情境。

## 🛠️ 本地数据分析工具（可选）

对于有技术背景的情侣或量化分析爱好者，项目提供了本地 Python 工具链（100% 离线运行，严守隐私）：

```bash
# 1. 微信/QQ 聊天记录统计分析（提取情绪刹车点、互动频率与高频词）
python tools/chat_parser.py 导出的聊天记录.txt --partner 小美

# 2. 本地情感记忆、纠偏记录与语料管理
python tools/memory.py correct 小美 --context "催吃饭" --feedback "只发生气的猫猫表情包"
python tools/memory.py search-corpus 小美 "火锅"
```
